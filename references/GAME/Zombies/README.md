# Zombie Visual References

These are first-party zombie appearance references for this game. Use them when creating thumbnails, icons, promotional art, or other visuals that include the game's zombies.

The set intentionally includes a representative range of zombie colors and threat levels rather than every zombie variant:

- `Walker.png` — baseline green and brown appearance
- `Runner.png` — lighter green variant
- `Brute.png` — darker heavy variant
- `Spitter.png` — bright toxic-green variant
- `Bomber.png` — red/orange variant
- `Frostbite.png` — cyan/ice variant
- `Summoner.png` — purple variant
- `Tank.png` — dark heavyweight variant

Preserve the blocky Roblox proportions, simple face, transparent background, and polished game-icon rendering style shown here.
