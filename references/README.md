# Visual References

Store source images for thumbnails, icons, promotional art, and other visual work in this folder.

Agents must inspect this folder before creating visuals that depend on Roblox avatars, characters, poses, outfits, game assets, or an established visual style. Relevant files here should be treated as the authoritative visual references unless the user gives newer instructions.

Use descriptive filenames where possible, such as `survivor-avatar-front.png`, `pyromaniac-outfit.png`, or `thumbnail-style-reference.jpg`.

The `thumbnails/` subfolder contains examples from popular Roblox experiences for composition and marketing-reference study. Treat them as third-party references only; do not copy or redistribute their artwork as this game's own assets.
